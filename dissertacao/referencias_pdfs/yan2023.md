# yan2023

**Título:** Multi-robot cooperative autonomous exploration via task allocation in terrestrial environments

**Autores:** Xiangda Yan, Zhe Zeng, Keyan He, Huajie Hong

**Ano:** 2023

**Venue:** Frontiers in Neurorobotics, vol. 17, artigo 1179033 (journal totalmente Open Access)

**DOI:** [10.3389/fnbot.2023.1179033](https://doi.org/10.3389/fnbot.2023.1179033)

**Página oficial:** https://www.frontiersin.org/journals/neurorobotics/articles/10.3389/fnbot.2023.1179033/full

## Abstract

The paper addresses the challenge of coordinating multiple mobile robots for efficient
exploration of unknown environments. Cooperative autonomous exploration is a challenging task
for multi-robot systems, which can cover larger areas in a shorter time or path length. The
research introduces a multi-robot exploration strategy incorporating three key components:
frontier grouping and clustering, task allocation using the Hungarian algorithm, and path
optimization. A notable contribution is the development of a self-healing mechanism that
enables the system to recover when robots fail, allowing remaining robots to reassign tasks and
continue operations. The method employs occupancy grid maps for environment representation
and uses frontier-based detection to identify unexplored boundaries. Testing demonstrates the
approach outperforms single-robot exploration by approximately 296% efficiency and maintains
robustness when individual robots malfunction, with completion time variations under 5% when
a single robot fails in a six-robot team.
