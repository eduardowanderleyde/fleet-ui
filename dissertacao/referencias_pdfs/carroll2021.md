## Abstract

Resh is a new, statically typed, interpreted programming language designed for coordinating
multirobot systems. Resh offloads much of the tedious work of programming such systems away
from the programmer and into the language runtime. It is based on a small set of temporal and
locational operators, and it is not restricted to specific robot types or tasks. The runtime
environment consists of three collaborative engines that execute Resh programs using available
robots in their operational environment. The paper documents both the language specification
and its runtime implementation, along with practical usage examples. The work was accepted for
presentation at ICRA'21.
