Features

Everything in one interface

From waypoint placement to RMSE analysis — without touching the terminal.

🗺️

Live SLAM Map

The SLAM Toolbox map streams in real-time to the browser. Click to place waypoints and visualise the robot pose as it moves.

🔴

Route Recording

Start recording, drive the robot to your waypoints, stop — the route is saved as a YAML file with poses captured at 5 Hz via TF.

▶️

Repeatable Replay

Load any saved route and replay it N times. Nav2 follows the exact waypoint sequence while sensor data is collected in MCAP bags.

📊

Repeatability Metrics

Automatic RMSE computation between runs, trajectory overlay plots, pairwise distance matrices, and 95% confidence intervals.

📡

Sensor Collection

LiDAR, odometry, and IMU data recorded into MCAP (rosbag2) during every run — ready for offline analysis and comparison.

🤖

Multi-robot Ready

Designed with robot roles (MUUT, FUUT, SU) and namespace support. Run in single-robot simulation or extend to a real fleet.

Quick Start

Up and running in minutes

Ubuntu 24.04 + ROS 2 Jazzy required.

1

Install prerequisites

ROS 2 simulation packages and Python backend dependencies.

# ROS 2 simulation packages
sudo apt install \
  ros-jazzy-nav2-minimal-tb4-sim \
  ros-jazzy-turtlebot4-navigation \
  ros-jazzy-tf2-ros ros-jazzy-tf2-py

# Python backend
sudo apt install \
  python3-fastapi python3-uvicorn \
  python3-websockets python3-yaml

# Node.js frontend
sudo apt install nodejs npm
2

Clone and build

⚠️ Path must be ASCII only — avoid accented letters (e.g. ~/Músicas/).

git clone https://github.com/eduardowanderleyde/fleet-ui ~/fleet-ui
cd ~/fleet-ui
bash build.sh          # colcon build + fix_ament_hooks
cd frontend && npm install
3

Open 4 terminals

Start them in order. Wait for "All BT navigator servers are active" before Terminal 2.

Terminal 1 — Simulation 
cd ~/fleet-ui/fleet_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash
ros2 launch fleet_orchestrator \
  turtlebot4_sim.launch.py
Terminal 2 — Fleet Nodes 
cd ~/fleet-ui/fleet_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash
ros2 launch fleet_orchestrator \
  fleet.launch.py \
  single_robot_sim:=true
Terminal 3 — Backend 
source /opt/ros/jazzy/setup.bash
source ~/fleet-ui/fleet_ws/install/setup.bash
cd ~/fleet-ui/backend
python3 main.py
Terminal 4 — Frontend 
cd ~/fleet-ui/frontend
npm run dev

# Open in browser:
http://localhost:5173
4

Record your first route

Open http://localhost:5173 in your browser, place waypoints on the map, and click Executar → record. The robot navigates and saves the route automatically.
